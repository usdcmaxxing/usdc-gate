🚀 Quick Start — Pay in 3 Lines

// 1. Install the x402 client npm install @x402/fetch // 2. Pay and call (agent-friendly, no API key) const res = await fetchWithPayment("https://usdc-gate-live.vercel.app/v1/dataset/sanctions"); // 3. Get your data const data = await res.json();

First request returns 402 Payment Required. Pay the challenge in USDC, retry, and get the data. No account, no API key, no subscription.

🔌 APIs

API $0.02

Counterparty Risk Check

POST /v1/check-counterparty
Pre-flight counterparty risk check for USDC payments. Checks Circle issuer blacklist (live on-chain), OFAC SDN, and on-chain flow patterns (shared funder, mixer exposure, peel chain). Returns APPROVE, HOLD, or REJECT.
Input: { payer, payee, chain?, asset?, amount? }
API $0.02

Token Price

Real-time token prices from CoinGecko. Single symbol or batch. Includes 24h change and market cap.

API $0.03

Wallet Risk Score

Broader wallet risk assessment (0-100): sanctions, issuer blacklist, on-chain activity, contract detection. More comprehensive than the counterparty check.
